# T_CustomParameters

## 補足

### プラグイン導入前の能力値算出方法

- param
  `(基礎値 + 加算値) * 倍率 * バフ倍率`
  - 基礎値 (paramBase)
    - アクター: 職業・レベルごとの値
    - 敵キャラ: 敵キャラごとの値
  - 加算値 (paramPlus)
    - アクター: アイテム等による加算 + 装備加算
  - 倍率 (paramRate)
    - アクター: ステート・アクター・職業・装備の特徴の累積
    - 敵キャラ: ステート・敵キャラの特徴の累積
  - バフ倍率 (paramBuffRate)
- xparam
  - アクター: ステート・アクター・職業・装備の特徴の累計
  - 敵キャラ: ステート・敵キャラの特徴の累計
- sparam
  - アクター: ステート・アクター・職業・装備の特徴の累積
  - 敵キャラ: ステート・敵キャラの特徴の累積
